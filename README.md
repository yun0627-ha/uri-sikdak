# 우리집 식탁 (2단계)

가족과 함께 쓰는 식단 캘린더 · 레시피 보관함 웹앱이에요. 휴대폰에서 '홈 화면에 추가'하면 앱처럼 쓸 수 있어요.

- **화면**: React + Tailwind CSS (Vite)
- **서버**: Supabase — 이메일 로그인, 데이터 저장, 실시간 공유, 식탁별 권한
- **AI 정리**: 내 Claude 채팅으로 정리하고 답을 붙여 넣는 방식이라 API 키 · 추가 비용이 없어요

---

## 들어 있는 기능

| | |
|---|---|
| 로그인 · 닉네임 | 비밀번호 없이 이메일로 받은 로그인 링크를 눌러 로그인 → 처음 한 번 닉네임과 내 색 정하기 |
| 식탁 여러 개 | 혼자 쓰는 식탁, 가족 식탁을 따로 만들고 오가기. 마지막에 쓴 식탁이 자동으로 열려요 |
| 가족 초대 | 설정 › 가족 초대 QR/링크 → 들어오면 '함께 고치기' 멤버. 만든 사람은 '보기만'으로 바꾸거나 내보낼 수 있어요 |
| 누구 아이디어 | 달력 메뉴 · 레시피 · 장바구니 오른쪽에 올린 사람 표시 |
| 친구 구경 | 설정 › 친구에게 구경시키기 QR → 로그인 없이 2주 식단 · 레시피를 읽기 전용으로. 마음에 드는 레시피는 '내 식탁으로 가져오기' |
| 달력 | 2주 보기(메뉴 칩) / 한 달 보기(끼니 색 점), 칩 앞 첫 글자로 아침 · 점심 · 저녁 구분, 오늘은 연두 동그라미, 날짜를 누르면 회색 기둥에 그날 메뉴 전부 + 누르면 레시피로, 위쪽에 이번 달 요약 |
| 레시피 서랍 | 오른쪽 아래 '레시피 서랍' 버튼 → 화면 아래에 뜬 칩을 **위로 끌어 날짜에 놓기**, 또는 칩을 누르고 날짜를 누르기 |
| 메뉴 추가 | "어떤 메뉴를 먹을까?" 시트 — 내 레시피북 / 직접 입력(약속 등) |
| Claude로 레시피 정리 | ① '정리 요청문 복사' → Claude 채팅에 붙여 넣고 영상 설명 · 자막 · 본문이나 캡처를 함께 보내기 ② Claude 답을 붙여 넣고 '채워 넣기' → 메뉴별로 자동 입력. 한 영상에 메뉴가 여러 개면 탭으로, '메뉴별로 나눠 저장'도 가능 |
| 레시피 | 종류별 보기, 재료로 검색('닭'), 냉털 검색, 즐겨찾기(사람마다), 별점 · 한줄평, 인분 계산, 요리 모드, 참고 링크, 원문 바로가기 |
| 장바구니 | 재료 옆 '장바구니'로 담기 → 같은 재료는 합쳐짐, 체크하며 장보기 |
| 통계 | 달력 위 요약을 누르면: 달마다 식사 수 · 외식 · 많이 먹은 메뉴 · 메뉴 종류 · 누가 많이 올렸나 · 별점 높은 메뉴 |
| 처음 안내 | 새 식탁에 '레시피 넣기 → 달력에 놓기 → 가족 초대' 3단계 카드 (다 하면 사라짐) |
| 같이 쓰기 | 가족이 고치면 바로 반영(실시간). 누가 접속해 있고 무엇을 고치는 중인지 표시 |
| 휴대폰 뒤로가기 | 화면마다 주소가 있어서 뒤로가기로 자연스럽게 돌아가요 |

## 설치 순서 (처음 한 번, 20분쯤)

### 1. Supabase 프로젝트 만들기
1. <https://supabase.com> 가입 → **New project** (무료 플랜으로 충분해요. 지역은 Northeast Asia(Seoul) 추천)
2. 왼쪽 **SQL Editor** → `supabase/schema.sql` 내용을 통째로 붙여 넣고 **Run**
3. **Authentication › Sign In / Providers › Email** 이 켜져 있는지 확인
4. 메일 템플릿은 건드리지 않아도 돼요. 기본 메일의 **Sign in** 링크를 누르면 로그인돼요.
5. **Authentication › URL Configuration** 의 Site URL 을 나중에 배포한 주소(예: `https://uri-sikdak.vercel.app`)로 바꾸고, Redirect URLs 에 `https://uri-sikdak.vercel.app/**` 를 추가해 주세요.
6. **Project Settings › API** 에서 `Project URL` 과 `anon public` 키를 복사해 둬요.

> 💡 Supabase 기본 메일 발송은 시간당 보낼 수 있는 수가 아주 적어요. 가족이 실제로 쓰기 시작하면 **Authentication › Emails › SMTP Settings** 에 Resend 같은 메일 서비스를 연결해 주세요.

### 2. 내 컴퓨터에서 실행해 보기
Node.js 18 이상이 필요해요.
```bash
npm install
cp .env.example .env      # .env 에 1-6에서 복사한 URL과 키 넣기
npm run dev               # http://localhost:5173
```

### 3. 인터넷에 올리기 (Vercel 기준)
1. 이 폴더를 GitHub 저장소에 올리기
2. <https://vercel.com> → **Add New › Project** → 저장소 선택
3. 설정은 그대로 두고 **Deploy** (Supabase 주소와 공개 키는 코드에 들어 있어요)
4. 나온 주소를 Supabase의 Site URL(1-5)에 넣기

Netlify 를 써도 돼요 (`public/_redirects` 가 들어 있어요).

### 4. 휴대폰에 설치
배포한 주소를 휴대폰 브라우저로 열고 → 공유/메뉴 › **홈 화면에 추가**.

## 폴더 구조
```
supabase/
  schema.sql                 테이블 · 권한(RLS) · 초대/구경 함수 · 실시간
src/
  lib/        supabase 연결, 상수(색 · 종류), 날짜/수량 도우미, Claude 정리 요청문 · 답 읽기
  hooks/      useAuth(로그인 · 닉네임), useTable(식탁 데이터 · 실시간 · 접속 표시)
  components/ 공통 UI, 메뉴 추가 시트, 카테고리 관리, 레시피 편집(Claude 정리), 요리 모드
  pages/      로그인, 닉네임, 내 식탁, 초대 들어가기, 친구 구경, 달력, 레시피, 상세, 장바구니, 통계, 설정
```

## 권한 정리
- **만든 사람(owner)**: 모든 것 + 멤버 권한 변경 · 내보내기 · 초대/구경 코드 새로 만들기 · 구경하기 끄기 · 식탁 지우기
- **함께 고치기(editor)**: 식단 · 레시피 · 장바구니 · 카테고리 · 식탁 설정 고치기
- **보기만(viewer)**: 보기, 별점 · 즐겨찾기만
- **구경 링크(로그인 없이)**: 최근 3주 ~ 앞으로 5주 식단과 레시피 읽기만

권한은 화면이 아니라 데이터베이스(RLS)에서 막혀 있어서, 앱을 우회해도 바뀌지 않아요.

## 알아 둘 점
- 1단계 프로토타입(Claude 안의 페이지)에 넣은 기록은 자동으로 옮겨지지 않아요. 필요하면 프로토타입의 '설정 › 데이터 › 백업 복사' 내용을 옮기는 스크립트를 따로 만들 수 있어요.
- 이 코드는 실행 환경 없이 작성돼서, 처음 `npm install` · `npm run dev` 때 작은 오류가 날 수 있어요. 오류 메시지를 그대로 알려 주시면 바로 고칠게요.
- 나중에 '버튼 하나로 자동 정리'를 원하면 Claude API(사용량만큼 별도 요금)를 붙이는 서버 함수를 추가할 수 있어요.
